# 原生像素浏览修正

用户明确要求原生像素，取代旧计划的 16px 降采样取舍。

根因：browser-pack.py 将 64×64/32×32 源帧缩成 16×16，ResidentIcon 再以显示尺寸放大，无法恢复丢失细节。

实现：保持源帧尺寸和 RGBA，不缩小、不滤波。按浏览顺序打包 1024×1024 无损 WebP 页，每格64像素，记录各帧真实16/32/64尺寸。逐帧验证编码后 RGBA 与源帧一致。沿用全部常驻索引，原生图集使用96 MiB有界解码/裁剪缓存，先当前页、后相邻页预热；过期工作取消。新包和缓存命名独立，旧16px缓存不再被此路径读取。

验证：带细节纹理的生成回归；帧索引跨页/原始尺寸测试；全量生成像素审计；实际页面canvas尺寸与原图像素抽检；连续翻页和配方仍可用。冷页可能需要加载原生图集，不再声称全库图像常驻或所有翻页零网络。
