# 极速浏览实现计划

范围：保持现有 Catalog、页面样式、物品身份和配方语义。生成独立浏览派生包，不修改原 Catalog。

1. 从全部 browse/texture 分片生成紧凑索引与静态首帧图集；按图集分组读取并验证 SHA256。限制轻量图标为 16px，独立记录清单与源 Catalog 身份。
2. 客户端准备索引和全部轻量图集；只有全部解码完成后标记极速模式 ready。Worker 负责筛选；页面内存切片，不调用逐页 HTTP。
3. 滚轮目标页按显示帧合并，丢弃过期结果。极速浏览使用已驻留真实图标，保持原配方高精度图集。
4. 轻量测试覆盖连续跨页、反向、重复、分组/搜索与准备失败回退。真实浏览器检查网络无逐页请求、图标就绪、配方仍可打开。
5. 构建独立前端与浏览包，更新本地入口，保留旧版本及证据。报告首次准备成本、常驻内存估算和热路径测量，不宣称未实测指标。
