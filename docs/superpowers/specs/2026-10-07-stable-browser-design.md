# 稳定浏览版本、个人备份和动画恢复

用户选择版本固化与收藏/设置导入导出，并要求修复浏览及历史图标静止。不实现缺料清单。

## 版本
将当前已验收产品及其契约/查询依赖建立清楚的历史基线提交，再分开记录动画和备份增量，验证后打本地发布标签并记录启动、回退与资源哈希。不推送。仅提交产品依赖及相关测试/构建脚本；诊断实验、巨大临时fixture和非当前契约压缩包保留未暂存。

## 备份
在现有设置中心提供JSON导出和文件导入。导出当前真正生效的浏览设置与按Catalog隔离的收藏；不夹带Catalog、浏览历史或任意localStorage。文件含格式名与版本，验证大小、结构、取值、标识和500收藏上限；导入先预览，再由用户点击应用。默认合并去重收藏，不清空已有收藏；设置采用经过验证的值。坏文件不改当前状态，写入失败显示错误。读取/导出纯本地，离线可用。

## 动画
根因：ResidentIcon只绘制一次首帧；历史硬编码enableAnimation=false；浏览包只含首帧，丢失时间线。保留现有首帧页和索引以维持NEI排序与快速翻页；从同一已验收Catalog派生原生图标动画时间线及小图页。运行时先画现有首帧，再按原生ticks/插值播放；只服务可见图标，离屏/翻页/卸载取消工作、释放图像，复用统一时钟和图集预算。不能以缩小图像、降低原生帧率或载入所有动画来换速度。

## 验证
备份往返、坏文件、合并/容量和实际设置生效；动画帧时序、取消及原生RGBA；轻量test/typecheck/build。浏览和历史分别采样有动画与无动画图标，快速翻页、候选切换、离线保存停服重开。新候选独立落盘，通过再更新3002，保留旧包和配置。
